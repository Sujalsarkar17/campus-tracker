# CampusTracker

## Project Description
CampusTracker is a campus tracking system designed to help users access campus-related tracking information through a simple web interface.

## Technologies Used
- HTML
- CSS
- JavaScript
- Java

## Project Files
- `index.html` – Website structure
- `style.css` – Website styling
- `app.js` – Frontend functionality
- `CampusTrackServer.java` – Java backend server

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Run the Java server using the appropriate Java command.
4. Open `index.html` in a browser.
